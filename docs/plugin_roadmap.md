# 从制作工程到可安装 Plugin

目标是让其他创作者安装后，使用自己的主题、正文与资产，制作延续 MathCoffee 表达
习惯的视频。当前仅完成通用框架与单期内容的仓库隔离；尚未提供 Plugin manifest、
安装入口、端到端新任务模板或发布包。

按以下顺序逐步完善，每一步用独立任务验证：

1. 定义稳定 authoring schema：场景／句子／事件 ID、数学假设、显示文案与声音锚点。
2. 抽出可配置的视觉风格：颜色、字体回退、留白、公式布局、字幕安全区和横竖屏规范。
3. 将依赖仓库布局的 CLI 改成独立包，分离安装目录、用户工作区、缓存与交付目录。
4. 补充从零创作的原创最小示例，覆盖低清全片、数学审稿、跨章承接与编码音轨验收；
   新示例需单独确认许可及纳入范围，不能复制频道历史单集代码或素材。
5. 基于目标宿主当时的 Plugin 规范组织 skills、工具和入口，提供能力探测与失败恢复。
6. 在干净环境验证安装、升级和卸载；审查项目授权、第三方依赖与字体／声音／资产条款，
   再决定开源许可证和公开发布。

每个里程碑记录可运行命令、实际结果和未验证项。插件安装不得触发隐式权重下载、
收费 API、声音克隆、发布上传或用户媒体清理；需要这些操作时遵从用户授权范围。
